# TinyRadi
radikoが最小限のUIになるChrome拡張機能。

## For Developers
```
git clone https://github.com/yyya-nico/TinyRadi.git
cd ./TinyRadi
npm install
```

### build
```
npm run build
```

## 拡張機能のインストール
- Chrome ウェブストア  
  https://chromewebstore.google.com/detail/tinyradi/alldnmeaajhblhaelbjgjjlcpnapcoho

## 手動で拡張機能をインストールするには
[Releases内のTinyRadi.zip](https://github.com/yyya-nico/TinyRadi/releases)をダウンロードし、展開後「パッケージ化されていない拡張機能を読み込む」でTinyRadiディレクトリーを選択してください。
